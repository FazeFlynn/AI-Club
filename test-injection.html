🧪 JavaScript Injection Test Page

Welcome to the Test Page!

This page is designed to test the JavaScript injection feature of the Split Browser Electron app.

📍 Injection Target Zone

The box below has id="toInjectJS" and is the target for injection:

⬇️ This is the ORIGINAL content inside the #toInjectJS div. ⬇️

When you inject HTML from the Electron app, this entire content will be replaced with whatever you specify in the injection textarea.

Try injecting something like:
<h2 style="color: green;">✅ Injection Successful!</h2>

ℹ️ How to Use

  1. Load this page in the Split Browser app (use file:///path/to/test-injection.html)
  2. Enter your HTML/JavaScript in the injection textarea
  3. Click "Inject Left", "Inject Right", or "Inject Both"
  4. Watch as the content in the bordered box above changes!
💡 Tip: You can inject any HTML, including:
  • Text with inline styles
  • Images with <img> tags
  • Buttons with onclick handlers
  • Interactive forms
  • Embedded videos

🎨 Example Injections to Try

Simple Text:

<p style="color: red; font-size: 24px;">Hello from Injection!</p>
